## What it implements

Four agents trained **from scratch with Deep Q-Learning (DQN)** on a `5×5` grid. Agents shuttle items **A (pick-up) → B (drop-off)** with **4 actions** (`Direction` Enum — north, south, east, west; no `wait` action), learning to coordinate and avoid **head-on collisions**.

- **One shared DQN** for all four agents (the assignment explicitly allows a single shared network): `Linear(19→128) → ReLU → Linear(128→128) → ReLU → Linear(128→4)`.
- **Purchased options (cost accounting):**
  - Sensors (cost **2**): neighbouring-cell observation augmenting the default 7-dim obs with 4 directions × (wall flag, any-agent flag, opposite-stream flag) = **+12 dims** → 19-dim observation.
  - Central Clock (cost **1**): agents act sequentially in round-robin order each tick (`0,1,2,3`).
  - **Total complexity cost C = 3.**
- **Q-learning rule** exactly as taught:
  `Q(s,a) ← Q(s,a) + α [ r + γ·maxₐ Q_target(s′,a) − Q(s,a) ]`
  implemented as Huber regression onto the TD target (`Adam`, lr `1e-3`, γ `0.95`, batch `512`, target net hard-synced every `2500` env ticks, grad-clip `10`).
- **Training trick: correlated ε-greedy** — with probability ε one random action is sampled and applied to *all four* agents (platooning); otherwise each agent acts greedily on the shared net. `ε: 0.08 → 0.01` over 220k steps. This keeps the four rovers moving as a coherent group, making opposite-stream encounters (~the only source of head-on collisions) essentially impossible while still letting the shared policy learn navigation.
- **Episode setup matches evaluation:** every training episode starts all 4 agents at B with random A/B cells, and episodes **terminate early once all 4 agents have delivered** (no post-task wandering → no avoidable collisions).

## What the notebook contains (run top-to-bottom)

1. **Environment (`ShuttleWorld`)** — `5×5`, 4 agents, `Direction` Enum, round-robin Central Clock, reward design (step `−0.5`, wall `−1.0`, pickup `+10`, delivery `+50`, collision `−25`/`−10`), head-on rule (mover/occupant on a non-A/B cell with opposite carrying flag), 19-dim observation with neighbouring-cell sensors.
2. **DQN (shared network)** — `QNet`, circular replay buffer (200k), `DQNAgent` (`.act`, `.greedy`, `.train_step`, `.sync_target`, `.param_checksum`).
3. **Training loop** — 1,450,000 agent-step cap, 510 s walltime guard, prints meters every 250 episodes.
4. **Evaluation** — `evaluate(agent, exhaustive=True)` over **all 600 scenarios** (25 B-cells × 24 A-cells, A≠B): all 4 agents start at B, must each complete one full delivery (B→A pickup→B drop-off) within 25 steps and zero head-on collisions. Greedy policy; `param_checksum` before/after asserts the **network is frozen** during testing.
5. **Results** — budget table, performance-points / α scaling, training curves.
6. **Worked example** — a pure-greedy rollout from B=(4,4) to A=(0,0) printed tick-by-tick.

### Performance / scaling

- Collision count `0 < 500` → collision performance points = **2**.
- Success rate `99.50 % > 95 %` → completion performance points = **2**.
- Performance points `B = 4`, complexity cost `C = 3` (sensors 2 + central clock 1).
- Scaling factor `α = 1 − (33/200) × max(0, C − B) = 1 − (33/200)·0 = 1.000`.

All three training budgets (step, collision, walltime) and the final performance
requirement are satisfied. No pre-trained models are used — training is from
scratch each run (only stdlib + NumPy + Matplotlib + PyTorch).
