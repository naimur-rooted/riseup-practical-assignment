## What it implements

Two rovers, **Type A** and **Type B**, must shuttle payloads back and forth
across a lake on a `5 × 5` grid whose state flips between **dry** and **raining**
every step (probability `0.5`).  Type A carries **U-payload**, which is
*destroyed if it enters the lake while raining*; Type B carries **R-payload**,
which is unaffected either way.  Each episode is a stream of `LAPS = 4` round
trips per rover.

- both rovers learn **independently** with from-scratch tabular Q-learning
  (same agent class, no communication, no joint action space);
- 5 actions: `north, south, east, west, wait` — pickup/delivery are automatic
  on the site/pad;
- reward design: **−5** move / **−3** wait / **+10** pickup / **+50** delivery;
  rewards stack additively (e.g. moving into rain: −5);
- **waiting costs less than moving (−3 vs −5)**, which makes "wait at the shore
  for the right lake state" a viable learned option — but the *crossing policy
  itself is never reward-shaped*;
- hashable Markov state per rover `(row, col, carrying, lake_bit)` with the
  **shared lake bit** read from the environment — the only channel through
  which the rovers influence each other (besides collisions when both are in
  the lake at the same time);
- NumPy Q-table `Q[row, col, carrying, lake_bit, action]` — `25 × 2 × 2`
  states × 5 actions = `500` entries per type;
- unbiased epsilon-greedy policy (random tie-breaking) with decay
  `1.0 → 0.02` (`0.9997` multiplicative);
- **γ-sensitivity study** (8 000 training episodes × 5 values of γ from 0.85 to
  0.995) showing that with a short horizon Type B reliably *free-rides* through
  the dry lake and the rovers collide;
- pure-greedy evaluation (`2 000` episodes) with the Q-tables **verified
  unchanged** (no learning during testing);
- Matplotlib visualisations (γ-study bars, learning curves, moving averages).

No reinforcement-learning libraries are used (stdlib + NumPy + Matplotlib only).

## Requirements

- Python ≥ 3.9
- `numpy`, `matplotlib`
- Jupyter (one of: `jupyter`, VS Code, `nbclient`)

## How to run

1. Install dependencies:
   `pip install numpy matplotlib jupyter`
2. Open the notebook and run **Kernel → Restart & Run All** (or `Run All`).
3. The notebook runs top-to-bottom without further input; every result is
   reproducible because all randomness is seeded (`SEED = 42`).

Training takes ~3 minutes on a normal laptop (the whole notebook ~5 minutes).

The two rovers converged to **complementary crossing schedules**: Type A only
enters the dry lake, Type B only enters the raining lake — so they never share
the lake and Type A never takes water damage.  This coordination goal is
*baked into the environment, not the rewards*: the rovers discover it purely
from the reward signal and the shared lake bit.

The result is robust across seeds: the same configuration trained with
`SEED = 99` and `SEED = 2024` also reaches `100 %` collision-free /
`100 %` water-free with all deliveries (`30 000` episodes, γ = 0.995).
