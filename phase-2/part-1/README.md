## What it implements

A complete, from-scratch **tabular Q-learning** solution for a single agent on an
`n × n` grid (default `n = 5`):

- parameterised `GridWorld` environment with 8 movement actions (incl. diagonals);
- item `A` drawn randomly **every episode**; fixed target `B = (n-1, n-1)`;
- automatic pickup on `A`, automatic successful delivery on `B`;
- hashable Markov state `(agent_r, agent_c, item_r, item_c, carrying)`;
- reward design `-1` move / `-2` invalid / `+10` pickup / `+100` delivery;
- NumPy Q-table `Q[ar, ac, ir, ic, carrying, action]`;
- unbiased epsilon-greedy policy (random tie-breaking) with multiplicative decay;
- standard Q-learning TD update with proper terminal-state handling;
- exhaustive **600-scenario** evaluation (25 starts × 24 item cells) using pure
  greedy actions with the Q-table verified unchanged (no learning during testing);
- Matplotlib visualisations (rewards, steps, moving averages, learned paths).

No reinforcement-learning libraries are used (stdlib + NumPy + Matplotlib only).

## Requirements

- Python ≥ 3.9
- `numpy`, `matplotlib`
- Jupyter (one of: `jupyter`, VS Code, `nbclient`)

## How to run

1. Install dependencies:
   `pip install numpy matplotlib jupyter`
2. Open the notebook and run **Kernel → Restart & Run All** (or `Run All`).
3. The notebook runs top-to-bottom without further input; every result is
   reproducible because all randomness is seeded (`SEED = 42`).

Training takes only a few seconds on a normal laptop.
